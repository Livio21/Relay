# Relay Zune test theme

This is a data-only Relay Theme Pack for testing the future importer.

- It uses the original Zune-style orange only for Relay's `signal` action color.
- It contains no executable code, fonts, scripts, shader source, or remote assets.
- It selects only Relay-provided layouts, artwork bleed, grain, and vignette. It cannot contain UI code, scripts, fonts, or shaders.
- It is not yet installable in the app; the Phase 9 Theme Pack import/apply UI is the next required host feature.
